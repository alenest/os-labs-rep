Пояснение к команде фильтрации студентов по первой букве фамилии
================================================================

Команда:
for f in *.txt; do
  first=$(basename "$f" | cut -c1)
  case "$first" in
    A|E|I|O|U|Y|a|e|i|o|u|y) head -n 1 "$f" ;;
  esac
done > /c/Users/User/Desktop/OS/os-labs-rep/лр2/vowels-start-surnames.txt

Разбор по частям:

1. for f in *.txt; do ... done
   Цикл по всем файлам с расширением .txt в текущей директории.
   На каждой итерации переменная f хранит имя очередного файла.

2. first=$(basename "$f" | cut -c1)
   Вычисление первого символа имени файла и запись его в переменную first.
   - basename "$f" — берёт имя файла без пути (например, ItskovIS.txt).
   - | cut -c1 — конвейер: результат basename подаётся на вход cut,
     который извлекает первый символ строки (например, I).
   - $( ... ) — подстановка вывода команды в значение переменной.

3. case "$first" in ... esac
   Сопоставление значения переменной first с набором шаблонов.
   - "A|E|I|O|U|Y|a|e|i|o|u|y)" — список латинских гласных (заглавных и строчных),
     разделённых символом |, который означает логическое «ИЛИ».
   - Если first совпадает с любой из этих букв — выполняется ветка ниже.

4. head -n 1 "$f"
   Вывод первой строки файла (ФИО студента).
   Кавычки вокруг $f нужны, чтобы имена с пробелами не разбивались на части.

5. ;; и esac
   ;; — конец текущей ветки case.
   esac — конец конструкции case (слово case наоборот).

6. > /c/Users/User/Desktop/OS/os-labs-rep/лр2/vowels-start-surnames.txt
   Перенаправление стандартного вывода всей команды в файл.
   Знак > означает перезапись: если файл существует, его содержимое будет
   заменено новым. Результат работы цикла (первая строка каждого подходящего
   файла) попадёт в этот файл, а не на экран.

Условие отбора:
   Задание требовало вывести студентов, фамилия которых в названии файла
   НЕ начинается на согласную, то есть начинается на гласную.
   Поскольку имена файлов записаны латиницей (транслит русских фамилий),
   в шаблоне перечислены латинские гласные: A, E, I, O, U, Y.
   Буква Y включена, так как в транслитерации она передаёт русские
   Й/Ы/Е/Ю/Я в начале фамилии (например, Yurkova — Юркова).
